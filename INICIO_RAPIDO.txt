⚠️ PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════════

Problema: "Python no encontrado"
Solución: 
  → Reinstala Python con "Add Python to PATH" MARCADO
  → Reinicia Windows

Problema: "npm: command not found"
Solución:
  → Instala Node.js desde https://nodejs.org/
  → Reinicia Windows

Problema: "WebSocket connection failed"
Solución:
  → Verifica que backend.bat esté corriendo
  → Abre cmd: netstat -ano | findstr :8000
  → Cierra lo que use puerto 8000

Problema: "API Key inválida"
Solución:
  → Verifica que .env tenga las claves correctas
  → No debe haber espacios extras
  → Prueba con claves nuevas

Problema: "Micrófono no funciona"
Solución:
  → Click en icono candado (izquierda de URL)
  → Permite acceso a micrófono
  → Actualiza página (F5)
