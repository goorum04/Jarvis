📄 EXPLICACIÓN DETALLADA DE CADA ARCHIVO
═══════════════════════════════════════════════════════════════════════════

🔵 BACKEND - siri_2.0_backend.py
───────────────────────────────────────────────────────────────────────────
QUÉ HACE:
  • Servidor FastAPI que escucha WebSocket en localhost:8000
  • Recibe audio/texto del móvil
  • Procesa con Claude o GPT-4
  • Convierte respuesta a audio (TTS)
  • Envía respuesta de vuelta al móvil

FUNCIONES PRINCIPALES:
  ✅ /ws - WebSocket bidireccional (chat en tiempo real)
  ✅ /api/chat - Endpoint REST alternativo
  ✅ /health - Health check
  ✅ /api/history - Ver conversaciones
  ✅ ConnectionManager - Manejo de múltiples clientes
  ✅ process_with_claude() - Integración con APIs IA
  ✅ text_to_speech() - Síntesis de voz

TECNOLOGÍAS:
  • FastAPI - Framework web rápido
  • WebSockets - Comunicación real-time
  • Anthropic - Claude API
  • OpenAI - GPT-4 API
  • Google Cloud TTS - Síntesis de voz

───────────────────────────────────────────────────────────────────────────

🎨 FRONTEND - JARVIS_Frontend.jsx
───────────────────────────────────────────────────────────────────────────
QUÉ HACE:
  • Interfaz holográfica tipo Iron Man
  • Captura voz del micrófono
  • Envía texto al backend
  • Recibe respuesta de audio
  • Reproduce audio automáticamente
  • Muestra historial de conversaciones

CARACTERÍSTICAS VISUALES:
  🔵 Diseño futurista azul neón
  ⬤ Efecto pulsante central
  〰️  Ondas de audio animadas
  📊 Visualizador de intensidad
  💬 Chat en tiempo real
  📱 Responsive para móvil

FUNCIONES:
  ✅ initializeWebSocket() - Conecta con backend
  ✅ initializeSpeechRecognition() - Captura voz
  ✅ sendMessage() - Envía texto al servidor
  ✅ playAudio() - Reproduce respuesta
  ✅ animateWaves() - Anima las ondas
  ✅ startListening() / stopListening() - Control de micrófono

───────────────────────────────────────────────────────────────────────────

📦 DEPENDENCIAS - requirements.txt
───────────────────────────────────────────────────────────────────────────
CONTIENE:
  • fastapi==0.104.1             → Framework web
  • uvicorn                       → Servidor ASGI
  • websockets                    → WebSocket
  • python-dotenv                 → Variables de entorno
  • anthropic                     → Claude API
  • openai                        → GPT-4 API
  • google-cloud-texttospeech     → Síntesis de voz
  • SpeechRecognition             → Reconocimiento de voz
  • pyttsx3                       → TTS fallback (local)

INSTALACIÓN:
  pip install -r requirements.txt

───────────────────────────────────────────────────────────────────────────

📋 CONFIGURACIÓN - .env
───────────────────────────────────────────────────────────────────────────
VARIABLES REQUERIDAS:
  CLAUDE_API_KEY=sk-ant-xxxxx    → Tu clave de Claude
  OPENAI_API_KEY=sk-xxxxx        → Tu clave de OpenAI
  GOOGLE_CLOUD_KEY=/path/json    → Credenciales Google (opcional)

CÓMO CREAR:
  1. Abre: .env.example
  2. Reemplaza xxxxx con tus claves
  3. Guarda como: .env (sin .example)

⚠️ IMPORTANTE:
  • NO subas .env a GitHub
  • Las claves son secretas
  • Cada clave es única para ti

───────────────────────────────────────────────────────────────────────────

🔄 FLUJO DE DATOS
═══════════════════════════════════════════════════════════════════════════

1. USUARIO habla al móvil
           ↓
2. FRONTEND captura audio con Web Speech API
           ↓
3. Se convierte a TEXTO con reconocimiento de voz
           ↓
4. Se envía TEXTO al BACKEND por WebSocket
           ↓
5. BACKEND procesa con Claude/GPT-4
           ↓
6. Se convierte RESPUESTA a AUDIO (Google Cloud TTS)
           ↓
7. Se envía AUDIO (base64) al FRONTEND
           ↓
8. FRONTEND reproduce el AUDIO automáticamente
           ↓
9. Se actualiza el HISTORIAL en la UI

🔗 CONEXIONES IMPORTANTES
═══════════════════════════════════════════════════════════════════════════

FRONTEND → BACKEND:
  Protocolo: WebSocket
  URL: ws://localhost:8000/ws
  Mensaje: JSON con tipo, texto, audio_base64

BACKEND → APIs EXTERNAS:
  Claude: https://api.anthropic.com/v1/messages
  OpenAI: https://api.openai.com/v1/chat/completions
  Google TTS: https://texttospeech.googleapis.com

FRONTEND → APIS NAVEGADOR:
  Web Speech API: Reconocimiento de voz
  Audio API: Reproducción de audio
  WebSocket: Comunicación bidireccional
